Objetivo: Comparar el funcionamiento y rendimiento de dos algoritmos de ordenacion interna.

Algoritmos seleccionados: 
- Insercion Directa
- QuickSort

Estructura del repositorio:

- Avances/: trabajos previos del proyecto
